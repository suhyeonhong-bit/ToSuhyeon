# 노션 시장 데이터 참고자료 설계

## 목표

`참고자료.md`에 노션 기반 시장 모니터링 데이터베이스의 링크 위치와 여덟 개 데이터 영역의 목적을 정리한다.

## 구조

문서는 다음 세 부분으로 구성한다.

1. 문서 제목과 노션 링크를 붙일 위치
2. 이 노션이 여러 데이터 레이어를 결합해 시장 국면을 판단하는 참고자료라는 짧은 설명
3. Fed·거시경제, 유동성, 시장 심리, 원자재 가격, 기업 실적, 뉴스·일정, 시장 가격, 통합 인사이트의 여덟 영역

각 영역에는 관찰하는 대표 지표와 해당 데이터를 보는 목적을 불릿으로 적는다. 기업 실적과 뉴스·일정 영역에는 현재 확인한 화면상 입력 행이 없다는 상태를 유지한다.

## 제약

- 실제 노션 URL은 제공되지 않았으므로 `노션 링크: 추후 추가`로 표시한다.
- 제공된 지표와 설명의 뜻을 바꾸지 않는다.
- 이 자료는 철강 과제의 필수 데이터 소스가 아니라, 별도의 시장 분석 참고자료임을 명확히 한다.
