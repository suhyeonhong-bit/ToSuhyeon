# STEEL SIGNAL 공개 대시보드 설계

## 1. 목적과 성공 기준

`STEEL SIGNAL`은 한국은행 기준금리, 미국 철강 생산자물가지수(PPI),
미국 연준 목표금리 중간값의
최신 값과 최근 5년 흐름을 한 페이지에서 보여주는 공개 웹
대시보드이다.

프로그래밍을 모르는 사용자도 페이지를 연 뒤 다음을 바로 이해할 수 있어야
한다.

1. 가장 최근 한국 기준금리와 미국 철강 PPI가 얼마인지
2. 두 지표가 지난 5년 동안 어떻게 움직였는지
3. 각 월의 정확한 값이 무엇인지
4. 데이터가 어디에서 왔으며 그래프를 어떻게 읽어야 하는지

대시보드는 개인 분석과 면접·업무 공유에 함께 사용한다. 링크를 받은
사람은 로그인 없이 볼 수 있어야 한다.

## 2. 결정된 방향

- 이름: `STEEL SIGNAL`
- 설명: `금리와 철강 가격의 흐름을 한눈에`
- 시각 방향: 차분한 시장 브리프
- 공개 범위: 링크를 받은 누구나 볼 수 있는 공개 사이트
- 첫 화면 우선순위: 최신 지표 카드와 5년 추이 그래프
- 그래프 기능: 월별 툴팁과 두 지표 각각 켜기·끄기
- 하단 기능: 데이터 출처, 그래프 읽는 법, 60개월 원본 표, CSV 내려받기
- 데이터 연결: 페이지를 열 때 공개 GitHub CSV를 직접 읽기

차분한 아이보리 배경, 짙은 남색 본문, 구리색 강조색을 사용한다. 금융
터미널처럼 어둡고 복잡하게 만들지 않으며, 홍보 페이지처럼 설명만
강조하지도 않는다. 보고서의 신뢰감과 웹 대시보드의 사용성을 함께
유지한다.

## 3. 범위

### 포함

- 최신 한국 기준금리 카드
- 최신 미국 철강 PPI 카드
- 월별 두 지표를 함께 보여주는 이중 축 추이 그래프
- 각 월의 정확한 값을 보여주는 마우스·키보드 툴팁
- 기준금리와 철강 PPI 선을 각각 켜고 끄는 버튼
- 최신 월부터 보여주는 60개월 전체 표
- 현재 읽은 CSV를 내려받는 버튼
- 한국은행 ECOS와 미국 FRED 출처 링크
- 단위 차이와 인과관계 해석 주의사항
- 로딩, 연결 실패, CSV 형식 오류, 결측값 상태
- 휴대전화, 태블릿, 데스크톱 반응형 화면
- 키보드 조작, 의미 있는 HTML, 읽기 가능한 색상 대비
- 사이트 공유용 소셜 미리보기 이미지
- 공개 웹 배포

### 제외

- 로그인과 사용자 계정
- 사용자별 저장, 메모, 알림
- 투자 판단 또는 철강 가격 전망
- 상관계수·회귀분석·인과관계 계산
- 기간 필터, 지표 추가, 국가 비교
- 관리자 화면과 별도 데이터베이스
- API 키를 브라우저나 사이트에 전달하는 기능
- 대시보드에서 FRED·ECOS API를 직접 호출하는 기능

## 4. 데이터 구조와 흐름

기존 데이터 수집기는 변경하지 않는다.

```text
매월 1일 오전 9시 30분
        ↓
GitHub Actions가 FRED·ECOS 수집
        ↓
원본 JSON 추가 + monthly_indicators.csv 갱신
        ↓
사용자가 STEEL SIGNAL을 열음
        ↓
브라우저가 공개 GitHub CSV를 읽고 화면을 그림
```

대시보드는 다음 공개 주소를 읽는다.

```text
https://raw.githubusercontent.com/suhyeonhong-bit/ToSuhyeon/main/data/processed/monthly_indicators.csv
```

페이지를 열 때마다 최신 CSV를 요청하므로 월요일 자동수집 후 대시보드를
다시 배포할 필요가 없다. 브라우저 캐시 때문에 이전 내용이 오래 남지
않도록 최신 요청을 사용한다.

CSV는 다음 네 열을 가져야 한다.

```text
month,korea_base_rate_percent,us_steel_ppi_index,us_fed_target_rate_percent
```

- `month`: `YYYY-MM`
- `korea_base_rate_percent`: 퍼센트 단위의 한국 기준금리
- `us_steel_ppi_index`: 미국 철강 생산자물가지수 수준
- `us_fed_target_rate_percent`: 연준 목표금리 상단·하단 중간값(%)

CSV 파싱과 검증은 화면 표시와 분리한 작은 모듈이 담당한다. 헤더, 날짜,
숫자 형식을 검사하고 유효한 월을 시간 오름차순으로 정렬한다.

최신 카드의 기준월은 CSV에서 해당 지표의 마지막 유효값이 있는 월이다.
두 지표의 최신 발표월이 다르면 카드마다 자신의 기준월을 따로 표시한다.
페이지 상단에는 수집 실행일이 아니라 CSV에서 확인한 가장 최신 데이터
기준월을 표시한다.

## 5. 화면 구조

한 페이지를 다음 순서로 구성한다.

### 상단

- 왼쪽: `STEEL SIGNAL`
- 오른쪽: `YYYY년 M월 데이터 기준`
- 제목: `금리와 철강 가격의 흐름을 한눈에`
- 설명: 한국 기준금리와 미국 철강 PPI를 월별로 연결해 시장 방향을
  살펴보는 페이지임을 짧게 설명

### 최신 지표 카드

- 한국 기준금리 값, `%` 단위, 발표 기준월
- 미국 철강 PPI 값, `지수` 단위, 발표 기준월
- 미국 연준 목표금리 중간값, `%` 단위, 발표 기준월
- 값이 없으면 추측하거나 이전 값으로 채우지 않고 `—` 표시

### 월별 지표 추이 그래프

- 가로축: 월
- 왼쪽 세로축: 미국 철강 PPI 지수
- 오른쪽 세로축: 한국 기준금리·연준 목표금리 %
- 철강 PPI: 구리색
- 기준금리: 남색
- 범례 버튼으로 각 지표를 독립적으로 켜고 끄기
- 포인터나 키보드로 월을 선택하면 월, PPI, 기준금리를 툴팁에 표시
- 결측 구간은 선을 억지로 이어 그리지 않기
- 두 지표가 서로 다른 단위를 사용한다는 사실을 축 제목과 설명으로 표시

### 읽는 법

- 그래프의 왼쪽 축은 PPI 지수, 오른쪽 축은 금리 퍼센트다.
- 같은 방향으로 움직여도 인과관계를 뜻하지 않으며, 세 지표의 발표 시차와
  단위가 다르다는 점을 함께 설명한다.

### 원본에 가까운 보기

- 읽는 법 아래에 전체 폭으로 배치한다.
- 표는 최신 월부터 과거순으로 표시
- 열: 월, 한국 기준금리, 미국 철강 PPI, 연준 목표금리 중간값
- 결측값은 `—`
- 좁은 화면에서는 표를 좌우로 밀어 볼 수 있게 함
- `CSV 내려받기`는 현재 대시보드가 성공적으로 읽은 CSV 내용을
  `monthly_indicators.csv`로 저장
- 한국은행 ECOS와 미국 FRED 원문 출처 링크는 읽는 법 안에 제공

### 하단

- 자동 갱신 일정: 매월 1일 오전 9시 30분 한국 시간
- 공개 GitHub 데이터 저장소 링크
- 데이터는 참고용이며 투자 판단을 제공하지 않는다는 짧은 안내

## 6. 구성 요소와 책임

- `DashboardPage`: 페이지 구역을 조합하고 상태를 전달
- `useIndicatorData`: CSV 요청, 재시도, 로딩·성공·오류 상태 관리
- `parseIndicatorCsv`: 헤더·날짜·숫자 검증과 월별 행 변환
- `MetricCard`: 최신 값, 단위, 기준월 표시
- `TrendChart`: 이중 축, 툴팁, 지표 켜기·끄기
- `IndicatorTable`: 60개월 표와 결측값 표시
- `DataGuide`: 단위, 출처, 해석 주의사항
- `DownloadCsvButton`: 성공적으로 읽은 CSV 내려받기
- `DashboardLoading`: 페이지 구조를 닮은 로딩 자리표시자
- `DashboardError`: 쉬운 오류 설명, 다시 시도, GitHub 원본 CSV 링크

각 구성 요소는 한 가지 역할만 가진다. 데이터 요청과 CSV 변환은 차트
내부에 섞지 않아 독립적으로 검사할 수 있게 한다.

## 7. 상태와 오류 처리

### 로딩

페이지 제목과 카드·그래프 모양의 자리표시자를 먼저 보여주고
`최신 데이터를 불러오고 있습니다`라고 알린다.

### 연결 실패

사이트 전체가 빈 화면이 되지 않게 다음을 표시한다.

- `데이터를 불러오지 못했습니다`
- 잠시 후 다시 시도하라는 설명
- `다시 시도` 버튼
- GitHub 원본 CSV 링크

원본 네트워크 오류 문자열이나 불필요한 기술 용어는 사용자에게 노출하지
않는다.

### CSV 형식 오류

필수 헤더가 없거나 유효한 월별 행이 하나도 없으면 잘못된 그래프를
그리지 않는다. 연결 실패와 같은 오류 영역을 사용하되
`데이터 형식을 확인할 수 없습니다`라고 구분해 알린다.

### 결측값

한쪽 지표만 없는 월은 정상적인 발표 시차일 수 있다. 표에는 `—`로
표시하고 그래프는 해당 지표의 결측 구간을 이어 그리지 않는다. 다른
지표의 값은 계속 표시한다.

## 8. 보안과 공개 범위

- 웹사이트는 공개 경제지표 CSV만 읽는다.
- FRED와 ECOS API 키는 기존 GitHub Actions secrets와 로컬 `.env`에만
  남는다.
- 브라우저 코드, 배포 파일, 오류 메시지, 네트워크 주소에 키를 넣지 않는다.
- 대시보드는 FRED·ECOS API를 직접 호출하지 않는다.
- 사용자 개인정보를 받거나 저장하지 않는다.
- 별도 분석 추적 도구를 추가하지 않는다.
- 공개 사이트와 CSV에는 누구나 볼 수 있는 기관 데이터만 포함한다.

## 9. 접근성과 반응형 동작

- 카드, 그래프, 표는 의미 있는 제목과 설명을 가진다.
- 지표 구분은 색상뿐 아니라 이름과 축 제목을 함께 사용한다.
- 토글은 실제 버튼으로 만들고 선택 상태를 보조기술에 전달한다.
- 그래프의 핵심 수치는 표에서도 모두 확인할 수 있다.
- 키보드로 지표 토글과 월별 값 확인을 할 수 있게 한다.
- 작은 화면에서는 카드와 본문을 한 열로 쌓는다.
- 표는 페이지 전체를 찌그러뜨리지 않고 자신의 영역에서 가로 스크롤한다.
- 불필요한 움직임을 넣지 않고 사용자 모션 감소 설정을 존중한다.

## 10. 검증

자동 검사 범위는 다음과 같다.

- 정확한 세 헤더를 가진 CSV 60개월 파싱
- BOM이 포함된 기존 CSV 헤더 처리
- 날짜 오름차순 정렬
- 숫자와 결측값 처리
- 잘못된 헤더·날짜·숫자 거부
- 두 지표의 마지막 유효값과 기준월 계산
- 로딩·성공·오류 상태 전환
- 다시 시도 동작
- 지표 켜기·끄기
- CSV 내려받기 내용과 파일명
- 출처 링크와 단위 설명 존재
- API 키 또는 `.env`가 배포 파일에 포함되지 않음

공개 전에는 자동 검사와 배포용 빌드를 통과해야 한다. 사용자 요청에
따른 별도 브라우저 조작 검사는 이번 범위에 포함하지 않는다.

## 11. 배포와 갱신

사이트는 공개 주소로 배포한다. 대시보드 소스가 바뀔 때만 다시
배포하며, 월요일 데이터 갱신만으로는 재배포하지 않는다.

공개 주소를 열면 그 시점의 GitHub CSV를 읽는다. GitHub의 데이터
커밋이 성공하면 다음 방문 또는 새로고침부터 최신 데이터가 보인다.

공유 링크의 미리보기에는 완성된 사이트와 같은 아이보리·남색·구리색
팔레트, `STEEL SIGNAL` 이름, 최신 지표를 연상시키는 간결한 시장 브리프
구성을 사용한다.
