# FRED 연준 목표금리 중간값 추가 설계

## 목적

기존 STEEL SIGNAL 월별 데이터 수집기에 미국 연방기금 목표금리 범위의
중간값을 추가한다. 기존 한국은행 기준금리와 미국 철강 PPI 수집 동작은
그대로 유지하고, 동일한 `FRED_API_KEY`를 사용한다.

## 설계

- FRED 수집 함수가 시리즈 ID를 인자로 받도록 확장한다.
- 기존 철강 PPI 시리즈 `WPU1017`은 기존 이름과 동작을 유지한다.
- 연준 목표금리 상단 `DFEDTARU`와 하단 `DFEDTARL`을 각각 수집한다.
- 동일 월의 상단·하단 값이 모두 있을 때 중간값을 계산한다.
- 한쪽 값이 결측이면 해당 월의 연준 금리도 결측으로 둔다.
- 최종 CSV에 `us_fed_target_rate_percent` 컬럼을 추가한다.
- 원본 JSON은 PPI와 연준 금리를 서로 다른 파일 접두사로 저장한다.
- 기존 테스트에 회귀가 없도록 요청 URL, 파싱, 월별 결합, 전체 워크플로를
  테스트한다.

## 데이터 흐름

```text
FRED WPU1017 ───────────────┐
FRED DFEDTARU ─┐           ├─ 월별 결합 ─ CSV
FRED DFEDTARL ─┘ 중간값 계산┘
ECOS 기준금리 ─────────────┘
```

## 오류 처리

- 세 FRED 요청은 기존 FRED 오류 처리 규칙을 따른다.
- 연준 상단·하단 중 하나라도 요청 또는 파싱에 실패하면 전체 수집을
  실패시켜 부분적으로 오래된 신호가 저장되지 않도록 한다.
- API 키, 원본 응답의 비밀 값, provider 오류 전문은 출력하지 않는다.

## 범위 제외

- 실효 연방기금금리 `DFF` 추가
- 일별 최종 CSV 제공
- 상관관계 분석 또는 신호 가중치 계산
- 대시보드 UI 변경
