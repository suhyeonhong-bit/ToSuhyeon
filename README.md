# 데이터를 직접 가져와서 일해보기

> **내가 궁금한 데이터 한두 개를 자동으로 가져와서 쌓이게 만드는 것.**

이 프로젝트는 이게 전부입니다. 내가 궁금한 숫자가 알아서 쌓이게 만드는 거예요. 예전엔 이런 걸 개발자만 할 수 있었는데, 지금은 AI한테 물어보면서 하면 됩니다. 코드를 못 써도 됩니다.

그래서 준비물은 딱 하나입니다. **내가 무슨 데이터를 보고 싶은지.** 그것만 있으면 시작할 수 있어요.

## 이 프로젝트를 세 분 모두에게 드리는 이유

원래 이건 수현님 한 분을 위해 만들기 시작했습니다. 직무가 영업/해외영업이고 나중에 철강 산업에서 세일즈를 하고 싶다는 방향이 뚜렷해서, 거기에 맞춰 자료를 만들고 있었어요.

그런데 만들다 보니 알게 됐습니다. 여기서 하는 얘기가 사실 철강이랑 별로 상관이 없더라고요. **데이터를 가져와서 내 일에 쓰는 방식은 직무가 뭐든 똑같이 적용되는 것**이었습니다. 그래서 방향을 바꿔서 세 분 모두에게 드립니다.

그 흔적이 남아 있어서 2번 문서엔 철강 얘기가 잔뜩 나옵니다. 그건 수현님 예시로 쓴 것뿐이니, 다른 직무의 두 분은 본인 직무로 바꿔서 읽으시면 됩니다.

## 어려운 말 먼저 풀고 갈게요

뒤에 나오는 문서들에 이런 단어가 자주 나옵니다. 여기서 한 번만 이해하고 가면 그다음부터는 술술 읽힙니다.

**API** — 데이터를 가진 기관이 "우리 데이터, 프로그램으로 가져가세요"라고 열어둔 창구입니다. 홈페이지가 사람이 눈으로 보는 문이라면, API는 프로그램이 드나드는 문이에요. 한국은행도, 미국 연방준비은행도 이런 문을 열어두고 있습니다.

**API 키** — 그 창구에 들어갈 때 보여주는 출입증입니다. "저 등록한 사람이에요"라는 표시예요. 각 기관 홈페이지에서 가입하면 무료로 발급해 줍니다. 출입증이니까 남에게 보여주거나 아무 데나 적어두지 않는 것만 조심하면 됩니다.

**스크립트** — "이 창구에 가서 이 데이터를 받아와"라고 적어둔 심부름 쪽지입니다. 한 번 써두면 컴퓨터가 그 쪽지를 읽고 몇 번이고 똑같이 심부름을 다녀옵니다. 이 쪽지를 쓰는 게 예전엔 개발자 일이었는데, 지금은 AI가 대신 써줍니다.

**원본(raw) 데이터** — 창구에서 받아온 그대로의, 아직 손대지 않은 데이터입니다. 가공하다가 잘못돼도 원본이 남아 있으면 다시 할 수 있으니까, 받아온 그대로를 한 부 따로 보관해 둡니다.

## 전체 순서

이 프로젝트는 크게 네 단계입니다.

1. **궁금한 데이터 고르기** — 내 일이나 관심사에서 "이 숫자 계속 보고 싶다" 하는 걸 하나 정합니다.
2. **API로 받아보기** — 출입증(API 키)을 발급받고, AI와 함께 심부름 쪽지(스크립트)를 써서 데이터를 실제로 받아봅니다.
3. **보기 좋게 쌓기** — 받아온 숫자를 노션이든 스프레드시트든, 내가 보기 편한 곳에 정리해서 쌓습니다.
4. **자동으로 돌게 하기** — 매일 아침이든 매주 월요일이든, 내가 정한 때에 이 심부름이 알아서 다녀오게 만듭니다.

4단계까지 가면 완성이지만, **지금 당장 필요한 건 1단계뿐입니다.** 나머지는 하나씩 하면 됩니다.

### 2번 문서를 읽는 법

2번은 수현님 예시라 철강 이야기가 가득하지만, **철강은 껍데기입니다.** 이렇게 바꿔서 읽으시면 됩니다.

- 다섯 가지 질문 → 내 산업에 던져보면 어떤 답이 나오나
- 철강 가설 표 → 내가 궁금한 건 뭔가
- 실무 요청 예시 → 내가 실제로 받을 법한 요청은 어떤 모양인가
- ECOS·FRED로 시작해보기 → 내가 필요한 데이터는 어디서 가져올 수 있나

본인 직무에 맞는 예시가 필요하면 같이 만들어봐도 좋습니다. 언제든 물어보세요.
